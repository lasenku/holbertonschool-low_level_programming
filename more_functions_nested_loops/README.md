# C - More functions, more nested loops

This project covers functions, nested loops, function prototypes,
header files, and variable scope in C.

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the Betty style
- No global variables
- No standard library functions (only `_putchar` is allowed)

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file containing the prototypes of all functions |
| `0-isupper.c` | Function that checks for an uppercase character |
| `1-isdigit.c` | Function that checks for a digit (0 through 9) |
| `2-mul.c` | Function that multiplies two integers |
| `3-print_numbers.c` | Function that prints the numbers from 0 to 9 |
| `4-print_most_numbers.c` | Function that prints the numbers from 0 to 9, except 2 and 4 |
| `5-more_numbers.c` | Function that prints 10 times the numbers from 0 to 14 |
| `6-print_line.c` | Function that draws a straight line in the terminal |
| `7-print_diagonal.c` | Function that draws a diagonal line in the terminal |
| `8-print_square.c` | Function that prints a square |

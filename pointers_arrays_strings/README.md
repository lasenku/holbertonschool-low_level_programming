# C - Pointers, arrays and strings

This project covers pointers, arrays, and strings in C.

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the Betty style
- No global variables
- No standard library functions (only `_putchar` is allowed)

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file containing the prototypes of all functions |
| `0-reset_to_98.c` | Function that updates the value pointed to by an int pointer to 98 |

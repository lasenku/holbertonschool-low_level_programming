# C - Variadic functions

This project covers variadic functions in C.

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the Betty style
- No global variables
- All header files are include guarded

## Files

| File | Description |
|------|-------------|
| `variadic_functions.h` | Header file containing the prototypes of all functions |
| `0-sum_them_all.c` | Function that returns the sum of all its parameters |
| `1-print_numbers.c` | Function that prints numbers, separated by a given string |

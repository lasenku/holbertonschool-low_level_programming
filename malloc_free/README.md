# C - malloc, free

This project covers dynamic memory allocation in C using malloc and free.

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the Betty style
- No global variables
- The only standard library functions allowed are `malloc` and `free`

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file containing the prototypes of all functions |
| `0-create_array.c` | Function that creates an array of chars, initialized with a specific char |
| `1-strdup.c` | Function that returns a pointer to a newly allocated duplicate of a string |
| `2-str_concat.c` | Function that concatenates two strings into a newly allocated space |
